# Calculadora

Aplicação de calculadora desenvolvida com C#, HTML e CSS, combinando lógica de backend com interface web simples.

## Funcionalidades

* Operações básicas (adição, subtração, multiplicação e divisão)
* Interface simples e intuitiva
* Integração entre frontend e backend

## Tecnologias utilizadas

* C#
* .NET
* HTML
* CSS

## Objetivo

Esse projeto foi desenvolvido com o objetivo de praticar a integração entre lógica de programação em C# e construção de interfaces web utilizando HTML e CSS.

## Estrutura do projeto

O projeto é dividido em:

* Backend em C# responsável pelas operações matemáticas
* Frontend em HTML e CSS responsável pela interface do usuário

## Possíveis melhorias

* Validação de entradas do usuário
* Histórico de cálculos
* Melhorias no design da interface
* Suporte a operações mais avançadas
